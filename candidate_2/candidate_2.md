## How To Run
To download the Data for this project automatically, ensure you have your kaggle credentials already setup. If this has not yet been set up, follow the instructins [here](https://www.kaggle.com/discussions/getting-started/524433 "getting started with kaggle api") to set up.

Once you are fully set up, Run the script in the `scripts` folder using the code below:
```python
uv run python .\scripts\download_data.py
```
